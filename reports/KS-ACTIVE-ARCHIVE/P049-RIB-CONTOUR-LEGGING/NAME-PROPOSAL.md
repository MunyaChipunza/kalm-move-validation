# Name proposal — P049

- Original supplier description: `High Waisted Ribbed Yoga Pants / Ribbed Leggings`
- Working customer-facing name: **KS Active Rib Contour Legging**
- Working slug: `ks-active-rib-contour-legging`

“Contour” is used only as a concise style descriptor for the fitted ribbed silhouette. It does not claim body shaping, compression, slimming, posture correction or performance benefits.

Munya approved this working name with the White representative review on 14 July 2026. That approval applies to the complete P049 review package only; public catalogue approval remains pending.
