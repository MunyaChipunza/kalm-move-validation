# Brand Notes

## Architecture

KALM Collective is the parent storefront. The five visible brands are:

- KS Active
- KALM Move
- KALM Outdoor
- KALM Wellness
- KALM Home

## Logo System

The KALM sub-brand display logos must use the approved buffalo device from the Drive branding folder, paired with the selected KALM sub-brand layout. Do not replace the buffalo with a newly generated substitute.

Approved logo files:

- `kalm-move-display-logo-a.webp`
- `kalm-outdoor-display-logo.webp`
- `kalm-wellness-display-logo-b.webp` uses the selected Wellness B lotus layout with the approved buffalo inside the lotus.
- `kalm-home-display-logo.webp` uses the selected KALM Home house layout with the approved buffalo inside the house.

Source files:

- `approved-kalm-move-source.png` is the provided KALM Move source image.
- `approved-kalm-nyati-source.png` is the saved buffalo source used in the KALM Wellness and KALM Outdoor selected layouts.
- `kalm-collective-logo.png` is the approved KALM Collective source logo.

Verdict remains unchanged: KALM Move is validation-ready, not bank-ready or production-ready.
